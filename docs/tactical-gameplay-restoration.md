# 技能与地图机制修复

本次处理大厅模型重叠、现有七名特工的技能释放与作用机制、六张导入地图的出生区和交互，以及无专属击杀徽章武器的原版回退。运行入口仍为 `dist/`，GitHub Pages 和既有 Sites 绑定未改动。

## 参考与还原状态

- 技能依据 Riot 官方角色介绍及 30 段演示视频。来源、视频参数和 SHA-256 见 [ability-reference-sources.json](ability-reference-sources.json)。已检查演示关键阶段；**未完成所有参考帧的手部关键点、轮廓和音频起点测量**。
- 技能道具和粒子使用重建几何；动作适配现有第一人称骨架，技能声音仍为合成提示。现有资源不包含七名角色完整的原版技能模型、动作和声音银行。因此这些部分不标为“完美还原”或“逐帧验证完成”。
- 地图继续使用仓库内的第三方 BSP 重建网格、材质、道具和天空盒。出生位置从首次地图导入提交 `caf84501122a81fd66459cea6e7f3166f8412453` 恢复；特殊机关位置在该重建坐标系内按平面图校准，未获得原版实体文件进行一一核对。购买区边界为出生区矩形范围，未声称等同原版屏障轮廓。
- 默认击杀徽章直接使用原版画面和对应的五档音效摘录，来源和文件哈希见 [default-kill-banner-sources.json](default-kill-banner-sources.json)。有专属资源时保留其徽章；缺少专属资源时使用默认徽章，技能击杀也走默认回退。
- 数值在 `agents-data.js` 和 `tactical-abilities.js` 中明确记录；本项目没有原版客户端的版本锁和自动补丁同步，未声称所有价格、持续时间均与某个实时补丁完全一致。

## 七名特工的释放和作用机制

| 特工 | 本次实现 |
| --- | --- |
| 捷风 | 烟雾投射及按住 C 引导；上升气流和长按跳跃滑翔；先准备、再按 E 的逐风及两次敌方击杀刷新；飞刀单发、右键齐射及单发击杀补刀。 |
| 贤者 | 屏障旋转、四段独立破坏、建成后加固和托起角色；减速球弹道及地面区域；准星队友治疗与右键自疗分开；锁定阵亡队友后延迟复活。 |
| 猎枭 | 震击箭、侦察箭按住蓄力、松开射出、右键循环 0/1/2 次反弹；侦察装置可破坏，三次有视线限制的脉冲；无人机手动移动、升降和标记；三发带前摇的穿墙终极射击。 |
| 不死鸟 | 向左或向右弯曲的闪光；可引导的分段火墙；火球落地后形成伤害区域并治疗本人；终极锚点倒计时或致命伤后返回，并保留已经消耗的护甲。 |
| 雷兹 | 正面扫描、反弹、追踪与近距离引爆的机器人；先投掷、再引爆的粘性炸药及自身免伤和位移；手榴弹四枚延迟子弹药；有飞行、接触引爆和后坐力的火箭。 |
| 丝凯 | 按住开火持续治疗，消耗公共治疗能量且不治疗自身；手动控制、可破坏并扑咬的猛虎；引导飞鹰、再次激活闪光及命中提示；追踪最近三名敌人的可破坏追踪灵。 |
| 炼狱 | 投掷式激励领域；反弹燃烧弹；战术地图添加、移除及批量确认最多三枚烟雾；战术地图选点的轨道打击和预警阶段。 |

选择技能不会立刻扣除次数。施放提交、蓄力松手、按住治疗和二次激活分别处理；切枪、死亡、回合结束和返回大厅会清理状态、模型及碰撞体。可切回尚未耗尽的飞刀、猎枭终极与火箭。

爆破手枪局初始只给一个免费招牌技能次数。购买界面新增技能购买和本购买阶段新购次数退款；未消耗次数保留到下一回合。团队对战维持完整技能配置。

## 地图与展示

- 六张地图每队生成五个分离站位，均留在恢复的出生区内，队伍朝向战斗区域。导航修正只能在附近寻找可站立点，不能再为了通路将出生点移到首个包点。
- 导航地面选取会排除 BSP 内部和没有实际碰撞支撑的渲染面；导航节点、门户和最终移动高度使用相同的实际地面规则。无效层级连接会被剔除；通过检查的连接会缓存，后续导航路线也需通过相同检查。裂变 A 点导入中心落在封闭底层，已改到距离原中心 1.70 米的可达包点平台，原坐标保留在 `sourceSites`。
- 亚海悬城：A 树屋门、B 市场门、终极技能球。
- 微风岛屿：廊道门、升降绳、终极技能球。
- 日落之城：B 市场门、终极技能球。
- 深海明珠：终极技能球。
- 莲华古城：A/C 旋转门、可破坏连通墙、终极技能球。
- 裂变峡谷：攻击方两条方向相反的单向横跨绳索、四处终极技能球。
- 桌面按 Z 交互；移动端复用交互/下包按钮。技能球要求持续按住一秒；松开会中断。机关和技能球在新回合重置。机器人只在关闭门前请求打开，避免持续开关。
- 大厅展示对混合材质中的手部、备用弹匣及隐藏附件逐三角过滤；游戏动作恢复原索引。WebGL 和无 GPU 的 Canvas 展示均按预览区域裁剪，防止模型覆盖皮肤列表和操作区域。运行模块和入口统一更新缓存版本。地图模型的遮罩纹理在生成 mipmap 前扩展透明区域的邻近可见颜色，避免蓝色底色污染远处树叶边缘；可见像素和原始资源文件保持不变。

## 验证

机制单元测试与主游戏输入测试分别执行。主游戏检查覆盖七名角色的 28 项技能、取消/大厅清理、双指弓箭蓄力，以及技能购买/退款。地图移动检查覆盖每张地图双方五个站位到所有包点，使用游戏的实际碰撞和步长推进，而非只检查图上存在路径。

截图见 `docs/verification/tactical/`。浏览器截图来自 Chromium WebGL（SwiftShader），用于界面及功能检查，不能据此声称真实手机性能或原版视觉一致性。

2026-10-05 回归结果：`npm test` 123 项通过；`npm run check:integration` 全部通过（含 130 条实际移动路线）。后续界面裁剪和技能球中断修正另通过 8 项渲染测试、24 项地图/技能测试及皮肤集成检查。Chromium 实际截图覆盖桌面、横屏、竖屏和关闭 WebGL 的 Canvas 预览，未出现页面脚本错误。
