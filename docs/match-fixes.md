# 回合经济与移动端战斗修复

- 爆破和排位的首回合、换边回合重置为标配、无甲、800 金币；大厅选枪只影响团队模式初始装备。正常回合按存活情况保留装备。
- 商店阻止重复购买同枪和同等级护甲，加入轻甲。购买阶段可退本阶段新购装备，替换新购武器自动结算差额；携带装备、战斗阶段及重复退款不能刷钱。
- 手机和平板大狙按住开火开镜，持续至少 120 毫秒后松手射击一次，射后退镜。多指释放、取消触摸、切枪、暂停和重置不会误射。
- 死亡后跟随存活队友视角，提供上一个/下一个按钮及方向键切换；目标死亡自动选择下一个队友。
- 散射使用实际移动速度，加入停止和反向输入的减速恢复；准星和状态条显示移动、空中、连射误差以及停稳状态。此为本项目调校，未声称原作数值完全一致。
