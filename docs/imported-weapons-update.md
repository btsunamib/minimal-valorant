# 用户提供的 ValStrike 武器资源导入（2026-10-02）

这次直接载入用户提供的五个压缩包，不再用手工几何和少量关键帧替代它们。原始资源的 SHA256、路径和大小见 `imported-weapons-sources.json`。资源作者信息仅能从包内目录（Shezo、Xeiv、MaikolArtzx、Jeck、@DR⁴ 等）辨认；没有额外杜撰出处。

## 明确的适配与缺项

1. 包里的手部贴图是全黑的加法混合占位。在 ValStrike 客户端中需要另行替换，直接显示会完全透明。本次保留原始手、指、手臂几何与骨骼动作，补充当前角色配色的可见材质。它不是原版角色手部贴图。
2. 白色塑水狂徒包没有终结模型，暂用包内蓝色终结；其他配色使用各自原始模型。
3. 包内未附带独立 1–5 杀音乐，2021 狂徒也没有枪声音频。没有把合成/现有音乐冒称为资源包原音。
4. 包内部分徽章帧故意是透明 1×1 TGA，保留其透明含义，没有补造新画面。
5. 没有附带原游戏的视频/相机参数。横屏视模采用 GoldSrc 常见的约 74° 垂直视场；竖屏扩大到 96°。仍需与实际游戏录像对照才能认定屏幕位置一致。
6. 没有原始游戏逐帧渲染或完整 ValStrike 客户端特效控制代码；Chrome 材质未重现原引擎环境映射，单独的 ADS 附件保存在资源目录但未另行叠加。这版不能称为原版无畏契约 1:1 验证完成。

## 验证

- `npm run check:integration`：通过真实 main.js 在模拟 DOM/Canvas 下检查五套武器加载、持握材质、检视/攻击/换弹、弹药恢复、暂停继续、切换回标准手枪、旧异步加载取消，以及原有购买/退款/狙击/观战逻辑。
- 离线绘制导入模型与手部绑定检查，图片在 `docs/qa/imported-weapons/`。这些是 CPU 离线渲染，不是浏览器或真机性能证据。
