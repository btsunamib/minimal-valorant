## 选择与装备

参考 [UX is Fine / Riot 的武器收藏详情图库](https://www.uxisfine.com/valorantgalleries)，实际查看了其 PC collection-skins.png 和移动端 VAL_Collection Vandal CHampions A_29042022.jpg。

- 深蓝绿展示空间、顶部武器/皮肤名、左侧缩略图网格、底部配色和装备按钮；手机竖屏用底部横向皮肤条。保留原有分类武器总览。
- 缩略图由导入后的真实蒙皮网格与包内原始纹理离线绘制，累计 100 张；不是通用枪图改色。
- 浏览状态与装备状态分离。每把枪用 `weaponSkins` 独立保存，迁移旧存档；配色在确认装备时保存。原有第一回合标配/800 经济规则仍生效，皮肤不会赠送长枪。
- 原始每条动作均可在展开的动作面板播放/慢放/前后寻帧。普通展示去除原本藏在 FPS 镜头外的备用弹匣、远处弹壳和特效零件；动作预览完整恢复原始三角索引和手部。
- 刀具收藏相机用其主平面呈现刃面，避免苦无侧面只显示一条细线；游戏内握姿仍完全采用资源包骨骼。
- 所有武器按需载入，解析缓存最多保留 4 件，重复音效按内容哈希共用；不会进入大厅就下载 100 个模型。

## 兼容与反馈

- 原文件不改写。离子正义 idle 和 PRIME 奥丁 zoom_idle 的源 FPS 为 0，按静态持握处理，可人工寻到任何原始帧；没有虚构额外运动。
- 起源雄鹿源动作分为 start_reload、insert、after_reload。游戏按缺失弹数串联完整换弹，逐壳入弹后更新弹药；打断保留已装入的子弹。动作预览可看完整流程及每一原始分段。
- 新枪械根据实际枪型选择原始射击序列，不再仅匹配 Vandal 名称。包中有枪声时使用原始 WAV；缺声资源使用原游戏项目的回退。
- 塑水宗、威龙各有 5 个不同的源音乐文件，以原速播放，爆头冲击独立叠加；新增原始徽章图层无损转 PNG。音效切换/暂停/死亡取消旧加载，避免迟到的异步回调复活旧声音。

## 验证和限制

`npm test` 覆盖所有 100 个模型的每个原始骨骼帧、原始事件与三角形、独立存档与装备、0 FPS 静态动作、展示索引往返、两组独立击杀文件。`npm run check:integration` 运行真实 main.js：全部 28 个新家族进入对局、切换/检视/射击/轻击/换弹、装备 VCT 队伍配色、独立枪械皮肤、模拟 390×844、844×390、1024×768、1280×720 展示区域中的模型投影、展示/动作切换恢复手部，以及原有经济/退款/长按狙击/多指/暂停检查。

`docs/qa/collection/native-model-contact.jpg` 为实际网格的离线 CPU 缩略图汇总，不是浏览器截图。当前环境无 Sites 要求的 control-browser，因此没有浏览器视觉验收或真机帧率数据。移动布局的投影检查使用模拟矩形，不能替代实际设备验证。

仍缺原游戏视频/镜头参数与客户端特效驱动程序；这些是第三方资源包适配，不能称原版无畏契约 1:1。徽章动态时间继续按现有项目适配，并非已对照原游戏全帧验收。新包侦察幻影、颗秒两件未附带 WAV，部分动作引用声音缺失，逐项保存在源清单。5 个独立 ADS 文件已原样保存，当前狂徒仍采用主视模里的 zoom_idle/zoom_shoot，未切换到独立 ADS 视模。原有白色塑水终结模型替代、手部占位材质、Chrome 环境映射差异仍存在。
