# 人机战术与追加资源 · 2026-10-05

运行版本：`20261005-ai-packs1`。本次包含人机升级以及用户随后追加的四个资源包。

人机有五种持续性格：敢打敢冲、沉稳守点、侧翼游走、照顾队友、灵活应变。性格影响交战距离、推进、侧翼路线、守点时间、队友支援和反应时间。回合目标轮换，携包者优先到点，游走者可分路；后期收拢。防守按点分工，收到真实敌情后回防，下包后由一个固定拆包者拆除，其余人掩护，拆包者死亡后接手。玩家暂停拆包时的半程进度不会让人机一直等待。

远处敌人须处于视野中并通过墙体、烟雾检查。敌人失去视野后只保存当时的位置；队伍首次报告有 0.6 秒延迟，情报会过期。枪声只有近距离、量化位置的线索。发射瞬间重新检查遮挡。交火使用短点射和停步，弹匣用完需换弹；低血量、受闪或换弹时尝试可达掩体。移动目标和掩体有决策间隔与保持时间，保留上次修好的路径跟随。原有难度命中率未提高。

技能按受伤队友、敌情、退路、友军位置和库存选择，使用现有技能运行时完成治疗、侦察、区域伤害、烟雾和适用终极技能。不自动释放需要额外遥控的宠物或可能困住队友的墙。记分板与观战显示性格。

模型原始字节以确定性 gzip 保留，音效不变调、不重合成。图标保持 alpha，生成适合屏幕显示的 lossless WebP；主副武器按钮截取图形，去除图片写死的弹药、文字。HUD 更新只改标签，不删除图片或按钮监听器。源包的静态 HUD/版本文字、没有网络功能的麦克风/无线电、未实现特工的语音及菜单背景音乐不覆盖实际游戏状态。

模型、音效及图标文件的来源、原始/输出 SHA-256、图标转换、全部 65 个原生动作、缺失音效事件见 `october5-extra-resource-sources.json`。盖亚戍卫缺少其事件引用的 `ashen_grab.wav`，鬼魅缺少 `reload_slideback.wav`；未用其他声音冒充这些缺失事件。

用户提供了原资源，未提供端游逐帧参考视频。原生帧可确定性播放与定位，但端游画面、手部接触、特效和音效起点的完整逐帧对照仍为 **unverified**。本次不宣称逐帧对照完成或像素完全一致。
