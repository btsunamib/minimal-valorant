# 武器展示与十月六日资源接入

版本：`20261006-collection1`。承接 `a79149e`；保持已有 AI、地图、光照、移动端操作和 GitHub Pages 部署。

## 行为

- 黑波两种原生模型分开计算刀身展示朝向，各自保留完整刀身和链条的独立展示范围，预留间隔。分离仅作用于收藏展示；原始持握、切换、检视和攻击动作不改动。
- 每次静态展示先重置父组变换，避免反复更新、缩放、切换动作后沿用上一次世界坐标。
- 武器总览分类按内容高度排列，防止压缩后的卡片溢出并覆盖下一个分类。手机两列网格行使用内容高度，超出屏幕时可滚动。卡片增加间距与边框，缩略图和名称分别占位；皮肤卡片增加间距。更新后的缩略图使用本站资源与版本参数。
- 接入用户提供的混沌狂徒、莲花 2.0 苦无/正义/狂徒、紫金爪刀，共五个模型与 54 段源动作。模型保留原始字节，使用确定性 gzip；WAV 不改录音内容；TGA 转为无损 RGBA PNG。缩略图由实际模型及内嵌纹理渲染。
- 混沌与莲花击杀横幅使用源层与五段各不相同的源 WAV；莲花苦无也采用套装横幅。

## 验证范围

- 全套 163 项单元测试通过；最终改动的相关测试复验通过。
- 新模型全部 5,662 个动作帧保持有限骨骼数据；来源、输出哈希与音效事件文件检查通过。正义和狂徒射击使用各自提供的样本。
- 实际收藏/装备/对局/射击/攻击/换弹路径通过；包含 GitHub 下载失败后的同场重试、子弹保存及模型/动作切换。
- Chrome WebGL / SwiftShader：新增五把武器与黑波五种模型配色，共 40 个模型和视口组合，检查完整模型边界、60 次连续更新、检视后恢复静态布局。1280×720、844×390、390×844、1024×768。
- 双刀完整展示面板最小投影间隔约 12.75 px；原始索引与所有动作的骨骼姿势可恢复，没有逐次累积偏移。
- 浏览器武器总览与反馈结果、截图保存在 `docs/qa/collection1/`。本次不是实体手机性能测试。QA 环境未装完整中文字体，截图中的方框为测试字体环境限制。

## 来源与限制

`docs/october6-resource-sources.json` 记录三份档案和 109 个源文件的哈希、转换、动作和缺失音效。所有动作的源游戏视频逐帧还原状态保持 `unverified`：用户提供原生模型包，未提供匹配的游戏视频，不宣称游戏画面 1:1 验证。

紫金爪刀包没有 WAV；混沌包没有射击 WAV。缺失部分沿用游戏通用音效，原包提供的动作音效与反馈照常使用。
