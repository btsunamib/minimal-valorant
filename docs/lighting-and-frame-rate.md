# 光幕、地图光影与帧率

移除训练地图和原生地图购买区的可视光幕；购买阶段移动范围仍由实际碰撞逻辑限制。六张 BSP 地图的纯青色 `aa_turkuaz` 封口面不再作为建筑显示，原始碰撞和导航数据保留。水面、蓝色玻璃和青色建筑纹理保留。

地图和静态道具保留贴图、顶点烘焙光照，叠加有限幅度的冷暖 Gradient Lambert 漫反射和动态太阳阴影。原生武器、人物衣服和皮肤继续使用原始调色板材质，不经过强 PBR 灯光增亮。敌方轮廓、骨骼动作和透明光效保留。

阴影跟随相机所在区域，并在光源空间按纹素对齐。均衡画质使用 1024 阴影贴图、最多每秒 30 次阴影更新；精细画质使用 2048 阴影贴图；流畅画质关闭动态阴影，保留地图冷暖光照。以上为实现预算，不是设备性能保证。

游戏没有固定 60 FPS 锁，默认不限帧，允许 60/90/120/144/165/240 渲染上限。设置新增一键取消游戏限帧、实际帧率、浏览器画面回调次数和主线程每帧工作耗时。回调次数同样受负载影响，不能据此把低帧率直接归因为浏览器锁帧。网页没有强制显示设备提高刷新率的通用接口。继续使用 requestAnimationFrame，不额外运行定时器制造不可见帧数。

缓存版本统一为 `20261005-lighting1`。

验证：127 项单元测试通过，主游戏/武器/收藏/技能集成检查通过；六张地图 130 条实际碰撞移动路线通过。Chromium WebGL / SwiftShader 对局截图确认购买区光幕与纯青封口面消失，着色器无 GLSL 编译错误。独立同场景开关阴影测试产生真实投影。截图见 `verification/lighting/`。浏览器回调诊断用 60/120/240 Hz 时间序列验证，未在真实高刷手机上测量，不宣称突破任何浏览器或系统上限。
