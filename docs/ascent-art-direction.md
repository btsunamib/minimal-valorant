# 空岛街区：Ascent 风格重建

用户希望画面与建筑风格转向无畏契约。本次选定亚海悬城 Ascent 为参考，不再沿用此前 Minecraft 苔藓石砖的美术方向。

## 实现

- 清除原有像素石砖、苔藓块、方块树、棋盘草皮、发光包点平台。
- 灰泥大色块、底部明暗渐变与局部露砖；线性滤波和 mipmap。
- 挤出弧形门窗、圆弧石框、百叶窗、檐口、水管、门把手、店铺招牌。
- 坡面红瓦屋顶、瓦行接缝、远景钟楼和穹顶、悬浮城块。
- 绿色金属掩体与对角加固梁，石拱通道。
- 石铺地面包含确定性生成的静态阴影和接触暗部，低画质也保留；这不是 Riot Lightmass 数据。
- 更克制的曝光、暖色定向光、冷色环境补光与远景雾；GPU 路径增加渐变天空。
- 人机改为圆润几何和更小头部，保留人机逻辑与瞄准判定对象。不是完整英雄角色模型。
- 原有碰撞、寻路、购买空气墙及包点位置保留。

## 验收与边界

这是一版参考重建，**不是 Ascent 1:1 地图或原版着色器**。仍使用原双包点场地布局；未复制地图精确尺寸、高低差、破坏门、原始模型、贴图、Lightmass 光照或角色骨骼。没有逐像素一致性证据，不能称为完全还原。

自动验证涵盖原有武器/输入/规则回归，新增检查确认物理掩体包围盒不变、静态批处理后射线距离不变、几何有限以及三角面与渲染批次预算。预算不是实际帧率承诺。

本次云端浏览器没有 WebGL，实机操作截图使用降级软件渲染；它不显示完整 GPU 光照，不代表手机 GPU 性能。高帧率档位保留，实际帧率应在用户设备测量。

验证结果：39 项测试通过。浏览器进入爆破购买阶段并显示空气墙；进入团队模式后空气墙不显示、HUD 显示 30 击杀目标。截图 `docs/qa/ascent-gameplay-software.jpg` 为降级渲染路径，不作原版一致性证据。
